# e-plantShopping

Paradise Nursery is a React plant shop application. It includes a landing page, company information, a product listing, and a shopping cart.

## Features
- Paradise Nursery landing page with a Get Started button
- About Us company information
- Plant product listings and Add to Cart buttons
- Shopping cart with quantity updates and item removal
- Automatic cart total calculation

## Run locally
1. Install Node.js.
2. In this folder, run `npm install`.
3. Run `npm run dev`.
4. Open the local URL shown in the terminal.
